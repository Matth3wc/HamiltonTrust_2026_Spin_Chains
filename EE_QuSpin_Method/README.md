# EE_QuSpin_Method — QuSpin spin-chain scaffold

This package provides a lightweight object-oriented scaffold for building,
diagonalizing and analysing spin chains with QuSpin. It includes modules for:

- configuration (`config.py`)
- basis construction (`basis.py`)
- Hamiltonian building (`hamiltonian.py`)
- diagonalization (`solver.py`)
- state tracking (`tracker.py`)
- observables (`observables.py`)
- sweep runner (`sweep.py`)
- basic plotting (`plotting.py`)

Run the tests with `pytest EE_QuSpin_Method/tests` from the repository root.
